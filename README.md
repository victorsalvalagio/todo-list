#  To-Do List

Uma aplicação simples de gerenciamento de tarefas desenvolvida para praticar **HTML, CSS e JavaScript**.

##  Funcionalidades

*  Adicionar tarefas
*  Editar tarefas
*  Excluir tarefas
*  Excluir todas as tarefas
*  Visualizar tarefas adicionadas

##  Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

##  Estrutura do projeto

```text
todo-list/
├── index.html
├── Style.css
├── script.js
└── README.md
```

##  Objetivo

Este projeto foi desenvolvido como parte dos meus estudos de desenvolvimento web, com o objetivo de praticar a integração entre **HTML, CSS e JavaScript** na criação de uma aplicação interativa.
